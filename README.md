# PC Power Calc - фронтенд

Тема 18: определение необходимой мощности блока питания для ПК.
Услуга - компонент ПК (`power_component`) с потребляемой мощностью и весом.

Бэкенд: [psu-calculator-backend](https://github.com/ManInTheCoat/psu-calculator-backend).

Стек: React 19, TypeScript, Vite, React-Bootstrap (Bootstrap 5), React Router.

## Лабораторная 5 - базовое SPA на React

Интерфейс гостя из двух страниц ЛР1: `плитка` и `лента`. Бэкенд в этой лабораторной не вызывается: данные карточек берутся из mock-коллекции `src/api/mock.ts`. Функции в `src/api/powerComponentsApi.ts` повторяют методы веб-сервиса `GET /api/power_components` и `GET /api/power_components/feed` (те же параметры и тот же формат ответа) и отдают данные с задержкой 300 мс, поэтому на странице виден индикатор загрузки. Redux и React Context не используются.

### Запуск

```bash
npm install
npm run dev
```

Приложение открывается в браузере само по адресу `http://127.0.0.1:3000`.

- `npm run build` - проверка типов и сборка в папку `dist`
- `npm run lint` - проверка кода ESLint

Фото в mock-коллекции - ссылки на MinIO (`http://127.0.0.1:9000/power-components/...`). Если MinIO не запущен, вместо них показывается фото по умолчанию.

## Страницы

| Адрес | Страница |
|---|---|
| `/` | перенаправление на плитку |
| `/power_components` | Плитка |
| `/power_components?max_power=300` | Плитка с фильтром по мощности |
| `/power_components/feed` | Лента, первый компонент |
| `/power_components/feed/3` | Лента, компонент с id 3 |
| `/power_components/feed/3?next=true` | Лента, следующий компонент после id 3 (после последнего снова первый) |

### Плитка - `/power_components`

Каталог опубликованных компонентов в два столбца.

| Элемент | Описание |
|---|---|
| Ползунок «Мощность до N Вт» | Значение фильтра от 0 до 500 Вт с шагом 10. Подпись над ползунком показывает текущее значение |
| Кнопка «Найти» | Применяет фильтр: значение записывается в адрес (`?max_power=300`), выводятся компоненты с мощностью не больше выбранной. Фильтр остаётся после поиска и после обновления страницы |
| Кнопка «Сбросить» | Убирает фильтр, ползунок возвращается на 500 Вт, выводятся все компоненты |
| Карточка компонента | Фото, название, мощность (⚡ Вт), количество лайков (♥). Клик по карточке открывает ленту с этим компонентом |

Если подходящих компонентов нет, выводится сообщение «По заданному ограничению мощности компоненты не найдены».

### Лента - `/power_components/feed/:id`

Один компонент на весь экран в вертикальном формате: видео проигрывается автоматически (без звука, по кругу), информация расположена поверх видео.

| Элемент | Описание |
|---|---|
| Видео | Видео компонента, до начала воспроизведения - его фото как обложка |
| Название и описание | Внизу слева. Длинное описание обрезается до 70 символов |
| Кнопка «ещё» / «скрыть» | Показывает полное описание или снова сворачивает его |
| ⚡ Вт, ⚖ г | Справа: поля по теме - потребляемая мощность и вес |
| ♥ | Количество лайков |
| Кнопка «След. →» | Переход к следующему компоненту: `/power_components/feed/{id}?next=true` |

Для несуществующего id выводится «Компонент не найден» и кнопка «К плитке».

### Нижняя панель вкладок

4 пункта: «Лента», «Добавление», «Плитка», «Вход». В ЛР5 доступны только «Лента» (открывает первый компонент) и «Плитка». «Добавление» и «Вход» неактивны: они понадобятся в ЛР6 после авторизации. Пункт текущей страницы выделен оранжевым.

## Фото и видео по умолчанию

Файлы лежат в самом проекте, в папке `public`: `default-component.png` и `default-component.mp4` (`src/media.ts`).

- Пустое поле `image_url` - в карточке плитки и на обложке видео ленты выводится `default-component.png`.
- Пустое поле `video_url` - в ленте проигрывается `default-component.mp4`.
- Ссылка заполнена, но файл не загрузился (например, MinIO не запущен) - фото подменяется в обработчике `onError`, видео переключается на заглушку через состояние `videoFailed` в `FeedVideo`.

В mock-коллекции у компонентов 4 и 6 поля `image_url` и `video_url` пустые.

## Компоненты

| Компонент | Props | Назначение |
|---|---|---|
| `AppLayout` | - | Шапка, `Outlet` для страниц и нижняя панель вкладок |
| `TabBar` | - | Нижняя панель из 4 пунктов (`Nav`, `Nav.Link`) |
| `PowerFilter` | `value`, `min`, `max`, `step`, `disabled`, `onChange`, `onSearch`, `onReset` | Фильтр плитки по мощности (`Form`, `Form.Range`, `Button`) |
| `PowerComponentCard` | `powerComponent` | Карточка плитки (`Card`, `Badge`) |
| `FeedVideo` | `videoUrl`, `imageUrl`, `title` | Видео ленты с заглушками |
| `FeedParam` | `icon`, `value`, `accent` | Плашка с полем по теме справа на ленте |

Состояние фильтра хранится на странице плитки (`PowerComponentsPage`), в `PowerFilter` оно передаётся через props `value` и `onChange`, а нажатия кнопок возвращаются в страницу через `onSearch` и `onReset`.

## Хуки

| Хук | Где | Зачем |
|---|---|---|
| `useState` | `PowerComponentsPage` | значение ползунка `maxPower`, список `powerComponents`, признак загрузки `loading` |
| `useState` | `PowerComponentFeedPage` | компонент ленты `feedItem`, `loading`, развёрнуто ли описание `expanded` |
| `useState` | `FeedVideo` | `videoFailed` - видео не загрузилось, нужна заглушка |
| `useEffect` | `PowerComponentsPage` | загрузка списка при открытии страницы и смене `max_power`; функция очистки отбрасывает ответ устаревшего запроса. Второй эффект ставит ползунок по адресу при переходе «Назад» |
| `useEffect` | `PowerComponentFeedPage` | загрузка компонента при смене `id` или `next` в адресе |
| `useSearchParams` | `PowerComponentsPage`, `PowerComponentFeedPage` | чтение и запись `max_power`, чтение `next` |
| `useParams` | `PowerComponentFeedPage` | `id` компонента из адреса |
| `useNavigate` | `PowerComponentFeedPage` | переход по кнопкам «След. →» и «К плитке» |
| `useLocation` | `TabBar` | выделение пункта текущей страницы |
